# JANOVEX

Site institucional da **JANOVEX**, empresa de tecnologia focada em desenvolvimento de sistemas, automação de processos, inteligência artificial aplicada e soluções web.

## 🌐 Site oficial

https://janovex.com.br/

## 🚀 Soluções

- Sistemas sob medida
- Automação de processos
- Inteligência artificial aplicada
- Sites e landing pages
- Integrações e APIs
- Soluções digitais para empresas

## 💡 Sobre a JANOVEX

A JANOVEX desenvolve tecnologia para organizar processos, reduzir tarefas manuais, melhorar o atendimento e ajudar empresas a crescerem de forma mais eficiente.

Atendimento em **Sabará, Belo Horizonte e região**, além de projetos realizados remotamente.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Google Analytics com consentimento
- SEO técnico
- GitHub / GitHub Pages

## 📁 Estrutura

- `index.html` — site principal
- `style.css` — identidade visual e responsividade
- `script.js` — interações e funcionalidades
- `politica-de-privacidade.html` — política de privacidade
- `termos-de-uso.html` — termos de uso
- `robots.txt` — configuração para buscadores
- `sitemap.xml` — mapa do site
- `favicon.svg` — identidade visual no navegador
